# diwali2026

A frontend project celebrating Diwali 2026, built with React, TypeScript, Vite, and Tailwind CSS.

## Scripts

```bash
npm install    # install dependencies
npm run dev    # start dev server
npm run build  # typecheck + production build
npm run preview
npm run lint
```

## Tech stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
